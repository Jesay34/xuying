# Roadmap

Xuying is still alpha. The roadmap favors reliability and transparent data handling over rapid feature growth.

## Near term

- Add automated tests for Telegram message grouping and filename ordering.
- Add fixtures for Immich API compatibility across supported versions.
- Add an optional authenticated Web deployment mode.
- Improve first-run diagnostics for filesystem hard-link support and permissions.
- Add export/import tooling for non-secret configuration.

## Later

- Pluggable source adapters beyond Telegram.
- More explicit rules for EXIF-based ordering and ambiguous media batches.
- Richer integrity reports for raw media, hard links, XMP and Immich assets.
- Container image publishing through GitHub Container Registry after release automation is stable.
